## Установка:
1. Клонируйте репозиторий:
```commandline
https://github.com/maks-batsmanov/OOP_homework
```
2. Установите зависимости:
```commandline
poetry install
```
## Документация
1. Модуль class_product.py содержит класс Product.
2. Класс Product имеет следующие свойства:
название (name),
описание (description),
цена (price),
количество в наличии (quantity).
3. Класс Product имеет следующие методы:
+ str выводит имя продукта, цену и остаток на складе.
+ add позволяет складывать количество товаров.
+ new_product класс метод, который принимает параметры и возвращает объект класса.
+ price возвращает цену товара
+ так метод позволяет установить новую цену, если новая цена больше 0
4. Модуль class_category.py содержит класс Category.
5. Класс Category имеет следующие свойства:
название (name),
описание (description),
список товаров категории (products).
5. Для класса Category есть два атрибута класса: category_count, product_count.
Доступ к этим атрибутам есть у каждого объекта класса. 
В них храниться общая информация для всех объектов. 
Эти атрибуты хранят в себе количество категорий и количество товаров.
6. Класс Category имеет следующие методы:
+ str выводит имя продукта и остаток на складе.
+ add_product добавляет продукты в в приватный атрибут списка товаров чтобы. 
Не может добавить вместо продукта или его наследников любой другой объект.
7. Модуль read_data.py содержит функцию create_object_of_class, которая 
принимает имя json-файла из папки data и возвращает объект класса.
8. Модуль class_LawnGrass.py содержит класс LawnGrass.
9. Класс LawnGrass наследственный класс от Product имеет следующие дополнительные свойства:
страна (country)
период прорастания семян (germination_period)
цвет (color)
10. Модуль class_Smartphone.py содержит класс Smartphone.
11. Класс Smartphone наследственный класс от Product имеет следующие дополнительные свойства:
эффективность (efficiency)
модель (model)
память (memory)
цвет (color)
